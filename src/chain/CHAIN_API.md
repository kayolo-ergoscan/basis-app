# src/chain — mainnet data layer

Everything the app knows about Basis on Ergo mainnet: a snapshot shipped with the app (`seed.json`, as of block
1 921 849, 2026-11-21 20:57 UTC) merged with a small live layer that polls the app's own `/v1` API.
Pages import from `@/chain` only (`index.ts`); nothing else in the app calls `/v1` for Basis data.

| file | what it is |
| --- | --- |
| `seed.json` | generated by `node scripts/make-seed.mjs` from `research/data/onchain.json`; 243 KB raw, 47 KB gzip; loaded lazily (its own chunk) |
| `types.ts` | `Seed*` (snapshot), `Api*` (/v1 shapes), decoded types, `*View` models, `Observatory`, `LiveData`, `TxDetail`, `BoxDetail` |
| `decode.ts` | pure: registers, Sigma constants, ErgoTree parse, template hash, P2PK/P2S addresses, base58, exit assessment, clocks |
| `api.ts` | the only network code: GET client, token bucket, per-block budget, retries, timeouts, request log |
| `model.ts` | pure: seed + live → `Observatory`; tx interpretation; box detail |
| `store.ts` | zustand vanilla store + scheduler (which request in which block); `chain` singleton |
| `hooks.ts` | React hooks (below) |
| `i18n.ts` | `chain.*` strings, EN + RU (honest-copy keys, see the end) |
| `links.ts` | explorer links (ergoscan.me only) |
| `dev/probe.html` | dev-only page, `http://127.0.0.1:5180/src/chain/dev/probe.html` (not a route, not built) |
| `ours/` | ErgoScan's own tracker, read-only, through `/api/tracker/*` (section "Our tracker" below) |

## Models (types.ts)

- `Observatory` — `useObservatory()`: `asOf`, `height` (+ `heightLive`), `contracts`, `reserves` (99 + live finds,
  newest first), `unspent`, `trackers`, `redemptions`, `incidents`, `tokens`, `labels`, `totals` (recomputed from the
  merged reserves), `snapshotTotals`, `owners`, `receivers`, `detector`, `hostIndex`, `live` (status), `warnings`,
  `index {reserves, trackers, redemptions, contracts, byTemplate}` (Maps for O(1) lookups).
- `ReserveView` — id, `source` seed|live, contract, kind erg|token, height/at/tx, origin, `unspent`, `spent`
  (`seenLive` when the live layer saw it go), prev/next (lineage), `value: bigint`, owner `{key, addr, label}`, nft,
  `collateral: TokenAmount`, r5 (AVL info), r6, r7, raw regs, issues, `legacy`, `exit: ExitAssessment` (unspent only,
  recomputed with live tracker states), `pending` (mempool txs, focus only; −1 unknown), `checked` (last live confirmation).
- `ExitAssessment` — `class` locked | refund | refund+redeem | redeem-if-tracker | redeem | refund+redeem-if-tracker,
  `redeem` now | if-tracker-posts | no, `refund` yes | pending | ready | no, `reason` (r4-invalid, r6-missing,
  r5-invalid, tracker-own-nft, tracker-unknown/live/unused/stale/locked/burned, with `emptyTree`), `emergency`
  (`EmergencyClock`), `refundClock {started, startedAt, completesAt, blocksLeft, ready}`, `line {en, ru}` (one sentence).
- `TrackerView` — nft, name (untrusted), `status` live | stale | burned | locked | unused, evidence, holder, currentBox,
  `lastTrackerBox` (the box the emergency clock counts from), keys, `commits` (+ live ones), `beats` (heights),
  `counts`, `emergency {boxHeight, age, open, opensAt, blocksLeft}`, `silentBlocks`, reserves, redemptions, `source`, `checkedAt`.
- `RedemptionView` — tx, height, contract, reserveIn/Out, owner, receiver, `amount: bigint` (+ `token`), tracker,
  `emergencyWindow`, fee, size; `TxDetail` (with `{detail: true}`) adds inputs/dataInputs/outputs with roles
  (reserve-in, reserve-out, tracker, payout, fee, change, funding), `kind` (redemption, top-up, refund-init,
  refund-complete, creation, other), amount, `trackerAge`.
- `BoxDetail` — any box: tree (header, version, constants), `templateHash`, matched `contract`, P2S check
  (`addressMatches`), P2PK key, registers decoded generically (`{name, hex, decoded {type, display}}`), Basis registers,
  `role` reserve | tracker | other, owner, tokens.
- `DetectorState` — `{watching: true, templates[{hash, short, total, checkedHeight}], found: DetectedBox[]}` for the two
  current templates (`2XoR` ERG, `8LeD` multi-token); `found` is `[]` until the first box appears there.
- `HostIndexView` — `{source, reserveCount, ergLockedNano, trackerCount, listedKnown, unspentHere, notListed, checkedHeight}`.
- `LiveStatus` — `{enabled, online, hidden, lastOkAt, lastError, changes, budget {perBlock, usedThisBlock, requests,
  avgLatencyMs, byLane}}`.

All amounts are `bigint` (the API sends strings); format them with the ui `money()` / `Num` helpers (ERG 9 dp, USE 3,
look-alike 6). Block counts with `fmtInt`.

## Hooks (hooks.ts)

```ts
useHeight(): HeightState                         // re-export of the shell's src/app/height.ts (one /v1/info poller for the app)
useObservatory(): Observatory | null             // null only while the seed chunk loads
useChainStatus(): LiveStatus
useReserve(boxId): { loading, reserve, tracker, lineage, redemptions }     // focus: box every 10 blk, its P2S mempool every 3
useTracker(nft): { loading, tracker, reserves, redemptions }               // focus: the NFT's unspent box every 2 blk
useRedemption(txId, { detail? }): { loading, redemption, detail, detailState, error }   // detail = one interactive /transactions
useDetector(): DetectorState                     // { watching: true, found, templates }
useBox(boxId): { state: idle|loading|ok|missing|error, box: BoxDetail|null, error, refresh }   // one interactive /boxes/{id}, cached
```

Every hook mounts the live layer (ref-counted `chain.acquire()`); with no hook mounted nothing is requested. The store
listens to the shell's height (`chain.onHeight`) instead of polling `/v1/info` itself. A new tracker box seen live goes to
the pulse bus as `pulse.commit({ source: "mainnet", trackerId, digest, height })`.

Without React: `chain.getObservatory()`, `chain.fetchBox(id)`, `chain.fetchTx(id)`, `chain.store.subscribe(...)`.
Pure helpers (no network): `decodeBasisRegisters`, `decodeConstant`, `parseErgoTree`, `templateHash` (WebCrypto SHA-256,
noble fallback) / `templateHashSync`, `p2pkAddress`, `p2sAddress`, `parseAddress`, `assessExit`, `describeExit`,
`emergencyClock(h, tip)` (open when tip − h > 2 160, opens at h + 2 161), `refundClock(r7, tip)` (ready at R7 + 43 200).

## Request budget

| rule | how |
| --- | --- |
| ≤ 2 requests per second for the whole app | src/chain: token bucket, capacity 1, refill 1/s (starts ≥ 1 s apart). The shell's `/v1/info` (once per 30 s) is the only other `/v1` traffic, so any 1-second window holds ≤ 1 src/chain request + ≤ 1 height poll. |
| ≤ 6 requests per block per visitor | block ≈ 120 s; the shell polls `/v1/info` every 30 s ≈ 4 per block → `heightReserve: 4`, src/chain spends 2 data requests per block. |
| interactive first | `useBox` / tx detail use the interactive lane: if the block is spent they wait for the next block (never fail); background work yields while one waits. |
| hidden tab | background requests are refused and nothing is scheduled; the shell's poller is the shell's. |
| slow chain | no new block for 240 s → a new budget epoch by time. |
| failures | 10 s timeout (AbortController); 2 retries on network errors, timeouts, 429, 5xx, backoff 800 ms ×2 + ≤ 30 % jitter; 404 is an answer, not retried. Every attempt counts against the budget. |

Scheduler (`store.ts`, `INTERVALS` in blocks; lower prio goes first; follow-ups such as a changed template's full list,
a vanished box's spending tx, are prio 0):

| prio | task | request | every |
| --- | --- | --- | --- |
| 1 | focused tracker (`useTracker`) | `/boxes/unspent/byTokenId/{nft}` | 2 |
| 1 | focused reserve (`useReserve`) | `/boxes/{id}` | 10 |
| 2 | mempool of the focused reserve's contract | `/mempool/transactions/byAddress/{P2S}` | 3 |
| 3 | detector, 2 current templates | `/boxes/byErgoTreeTemplateHash/{hash}?limit=20` | 6 |
| 4 | live trackers (3) | `/boxes/unspent/byTokenId/{nft}` | 6 |
| 5 | legacy templates with unspent reserves (6) | `/boxes/unspent/byErgoTreeTemplateHash/{hash}?limit=1` (signature); on a change one `?limit=50` full list | 12 |
| 6 | stale / unused trackers (2) | `/boxes/unspent/byTokenId/{nft}` | 20 |
| 7 | host index | `/defi/basis` | 360 |

Steady state with no focus: 2/6 + 3/6 + 6/12 + 2/20 + 1/360 ≈ 1.44 requests per block of the 2 available, so a full
sweep of all 14 targets takes about 7 blocks after page load (tested: 14 distinct targets within 10 blocks, ≤ 2 per
block). A tracker page adds ≈ 0.33, a reserve page ≈ 0.43; when the sum exceeds 2, low-priority tasks wait, nothing
is dropped. An NFT is called burned only after empty answers in two different blocks. If the shell's height poll moves
to 60 s, set `heightReserve: 2` and src/chain gets 4 per block with no other change.

## Our tracker (`ours/`, read-only)

ErgoScan's Basis tracker on mainnet: NFT `f5178dc4…e3f29f`, minted at block 1 922 275 (tx `0841b442…`), address
`9gMR2W…hW3W` (`OUR_TRACKER` in `ours/types.ts`). The browser reaches it only at the same-origin path `/api/tracker/*`:
in dev, vite strips the prefix and proxies to the nginx front on 127.0.0.1:3050, which adds the key; in production
Caddy does the same (`handle_path /api/tracker/* { reverse_proxy 127.0.0.1:3050 }`). No key ever reaches the browser.

| route (`/api/tracker` + …) | used for | cadence |
| --- | --- | --- |
| `/tracker/state` | status, box, committed and live digest, height, commit in flight | 30 s while the tab is visible |
| `/reserves` | reserves whose R6 is our NFT, totals | 120 s while the tab is visible |
| `/key-status/{pk}` | key lookup on `/tracker/mainnet` | on demand, one at a time |
| `/config/reserve-collateral` | client method only | not polled |

Fee funds are the confirmed, unspent, token-free boxes at the tracker address, from
`/v1/boxes/unspent/byAddress/{address}?limit=100` through `api.ts` (they count in the per-block budget). The box that
holds the tracker NFT (0.001 ERG) is not fee money and is not counted; a list with more pages makes the sum a lower
bound, shown with "≥". Only pages that show them ask (`useOurTracker({ fees: true })`): the first read of a visit is
asked at mount, before the tracker polls, on the interactive lane, so it takes one of the block's two /v1 slots ahead of
the chain module's background checks (and waits for the next block only when the budget is already spent); later reads
use the background lane, at most every 30 min or when the tracker box moved.

- `client.ts`: one FIFO queue per visitor, ≥ 1 s between the starts of tracker requests (polls and lookups); 10 s
  timeout; `credentials: "omit"`, `cache: "no-store"`. Envelope `{success, data, error}`. u64 amounts are quoted
  before `JSON.parse` and become `bigint`. Ratio 999 999 means "no debt" → `null`; `collateralization_ratio` is
  collateral / debt (2.0 = 200 %). Failures: 404 `notFound`, 429 `rate` (Retry-After honoured), 502/503/504
  `unavailable`, `timeout`, `network`, `shape`; an invalid key is refused before any request.
- `/reserves` carries `total_debt` and `collateralization_ratio`, but this tracker version does not compute them (debt
  stays 0, the ratio comes back null: upstream `specs/PRODUCTION_READINESS_AUDIT.md` item 6; seen on 22 Nov: 0 in the
  list while `/key-status` said 0.3 ERG). Pages never show them; the reserves tables link to the key lookup, which
  computes debt from notes.
- `store.ts`: polls nothing while the tab is hidden or no page watches (ref-counted `acquire()`). Backoff after a
  failure: 30 s × 2^(n−1), at most 10 min, +0–20 % jitter, never shorter than Retry-After; key lookups are refused while
  a 429 backoff runs. The last good answers are saved in localStorage `basis.ours.v1` (≤ 256 KB) and shown as a saved
  answer with its age until a fresh one arrives.
- `model.ts`: status `connecting` (no answer yet), `live` (box at most 750 blocks old: the 720-block heartbeat plus 30
  of slack), `stale` (older), `unreachable` (the last state request failed; a 429 after an answer keeps the answer).
  Totals never mix ERG and tokens.
- Events (the MAINNET tape on `/tracker/mainnet` and the Network page): a commit when the confirmed box or digest
  changes (same digest = heartbeat), a reserve when a new owner + denomination bound to our NFT appears. The first
  answer of a visit and saved answers are the baseline, never events. One pulse per new commit
  (`pulse.commit({ source: "mainnet", trackerId: nft, … })`), not repeated if the bus already has it.
- The seed (block 1 921 849) predates the NFT: every snapshot count of tracker NFTs adds it once (`oursExtra(obs)`:
  the Network bar, strip and list, Home and the tracker page's mainnet card) until the seed is regenerated, and counts
  of unspent tracker boxes add it once its API has named its box (`useOursInCounts(obs).withBox`: the Network strip,
  Home's "Trackers by status" and its mainnet door). `/network/tracker/<our nft>` is served from the tracker API, not
  from the chain store.
- Hooks: `useOurTracker({ fees? })` → `OurView`, `useOursInCounts(obs)`, `useKeyLookup()`, `useAgo()`, `useNow()`.
  Tests: `ours/ours.test.ts`.

## How to add an endpoint

1. Probe it by hand, paced: `curl -sS --rate 1/s -w '%{http_code} %{time_total}s %{size_download}B\n' …` against
   `http://127.0.0.1:4401/v1/…`; add a row to the table above and an `Api*` type to `types.ts` (amounts `string`).
2. Add a path builder to `paths` in `api.ts`. Never call the node, never another origin.
3. User-initiated: a store action like `fetchBox` that calls `api.get(path, { lane: "interactive" })` and caches a
   `Fetched<T>`; expose it through a hook.
   Background: add a `TaskKind`, its handler in the task switch, and an `add({ key, kind, arg, prio, every })` line in
   `targets()`. Keep the steady sum of `1/every` under ≈ 1.8 per block (now 1.44).
4. Merge the answer into `LiveData` with `set()` (never mutate the seed); `buildObservatory` recomputes the views.
   Mark changed records `source: "live"`, bump `live.changes`, and commit a pulse only for a new tracker commitment.
5. Test it with the fake fetch in `store.test.ts` (`quietChain()`): requests per block stay ≤ 2, nothing changes on a
   quiet chain, the new case changes exactly what it should.

## Honest copy for the Network page

Keys are in `i18n.ts` (EN + RU). Numbers inside strings use U+2009 U+2060 as the thousands separator.

- Say where every number comes from: `chain.asOf` (“as of block {height}”) for the snapshot, `chain.live.checked` for a
  live check, `chain.live.seedOnly` when a record was not checked live yet. `chain.live.source.seed|live` for tags.
- Frame it as test use: `chain.testUse`. Never “launched”, “live on mainnet”, “official”.
- Exit per reserve: `chain.exit.<class>` (full), `.short` (tags), `.help` (one-paragraph explanation);
  `reserve.exit.line[lang]` is the per-box sentence (reason, clocks, tracker silence).
- Trackers: `chain.tracker.<status>` + `.help`. “Box unspent” only means the NFT's box exists, not that anyone runs a
  tracker; show `silentBlocks` with `chain.tracker.silent`. Always `chain.tracker.honest` (“Cannot steal · Can censor”),
  `chain.tracker.untrustedName` next to minted names, `chain.tracker.keyNotHolder` next to keys.
- Clocks: `chain.emergency.open` / `.opensAt` (2 160 blk ≈ 3 days, opens at tracker box height + 2 161),
  `chain.refund.running` / `.ready` / `.none` / `.notInContract` (43 200 blk ≈ 60 days). Never “7 days”.
- Contracts: `chain.contract.current|legacy|superseded|repo-only`, `chain.contract.legacy.refundable|noExit`
  (exploitable: refund or migrate), `chain.contract.msWindow` for the early W52 constant.
- Fees: `chain.fee.protocol` (“Protocol fee: none (basis.es)”). Never “2 %”, no yield/APY wording.
- Tokens: `chain.token.use`, `chain.token.lookalike`; show the look-alike apart, never add it to USE.
- `chain.detector.none|found|checked`, `chain.hostIndex` (“ErgoScan's Basis page lists 17 of the 58 unspent reserves.”),
  `chain.basisNames`, `chain.malformedOwner`, `chain.receipt.*`, `chain.box.*`.
- Never: trustless, guaranteed, safe, unstoppable, live on mainnet, launched, official, yield/APY, “7 days”, “2 %”,
  bearer (`i18n.test.ts` checks every EN/RU string and the EN/RU key and placeholder parity; `model.test.ts` checks
  every per-reserve exit line).
- Links: `explorer.tx|address|token|box|block` (ergoscan.me only; `/box/` and `/block/` not verified yet).

## Known gaps

- Only the current box of a tracker NFT is read: commitments posted between two checks are not seen (the seed's beats
  are complete up to block 1 921 849).
- Full template lists use one page of 50: if a template ever holds more than 50 unspent boxes, spent boxes there are
  not inferred until paging with `cursor` is added.
- Mempool is polled only for a focused reserve's contract.
- `hostIndex` in the seed comes from KNOWLEDGE (2026-11-21), not from the snapshot file; the live check replaces it.
- Readable tracker boxes: 1 492 in the snapshot vs 1 493 in KNOWLEDGE.
- The budget assumes the shell polls `/v1/info` every 30 s; a faster shell poll would break the 6-per-block count.
